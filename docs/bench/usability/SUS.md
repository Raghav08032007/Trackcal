## Scoring (for the facilitator)

1. For each odd-numbered statement (1, 3, 5, 7, 9), take the answer minus 1.
2. For each even-numbered statement (2, 4, 6, 8, 10), take 5 minus the answer.
3. Add up the ten values, which gives 0–40, and multiply by 2.5. The result is the SUS score, from 0 to 100.

**Worked example.** Answers 4, 2, 4, 1, 4, 2, 5, 1, 4, 2:
- Odd statements: 3 + 3 + 3 + 4 + 3 = 16.
- Even statements: 3 + 4 + 3 + 4 + 3 = 17.
- Total: (16 + 17) × 2.5 = **82.5**.

**Reading the score.** About 68 is average, 80 or more is good, and under 50 is poor. SUS is not a percentage. With 5 people, report the mean and the range, not a significance test.

If an answer is missing, ask the participant to fill it in before they leave. If it is still missing, don't score that form, and say so in the report.
